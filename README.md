## Cómo funcionan las herramientas

- Son páginas HTML estáticas, sin instalación ni cuenta.
- Lo que escribes se guarda solo en tu navegador (`localStorage`). No hay base de datos y nada se envía a ningún servidor.
- El nombre de la iniciativa y el autor se comparten entre las herramientas para no escribirlos dos veces.
- Cada herramienta permite descargar el trabajo en Word o PDF, o copiarlo como texto, con fecha y hora como versión.
- Los prompts se copian y se pegan en Copilot, ChatGPT o Claude.
- Están en español y en inglés.

## Caso de ejemplo

Todas las herramientas incluyen un ejemplo ficticio: un Kam (Key Account Manager) de un laboratorio farmacéutico que vigila a mano licitaciones, pagos, regulación y competencia de sus cuentas. El laboratorio, los productos y las personas son inventados.
